# Sogeri Floriculture

A responsive website project built for **Assignment 3** at PNG University of Technology.  
This site showcases tropical flowers and plants from the lush hills of Sogeri, Papua New Guinea, while demonstrating modern web design techniques.

---

## Purpose
The purpose of this project is to apply **responsive web design principles** using HTML5, CSS3, Flexbox, Grid, and Media Queries.  
It ensures the site adapts seamlessly across desktop, tablet, and mobile devices.

---

## Technologies Used
- **HTML5** — semantic structure and accessibility
- **CSS3** — styling, variables, transitions, animations
- **Flexbox** — navigation, header, and horizontal layouts
- **CSS Grid** — multi‑column layouts for About, Services, and Gallery sections
- **JavaScript (ES6)** — interactive navigation toggle, reveal animations, active link highlighting

---

## Responsiveness
- **Desktop:** Full multi‑column layouts with balanced spacing
- **Tablet:** Adjusted grids (`max-width:1024px`) for readability
- **Mobile:** Stacked layouts (`max-width:800px`) with simplified navigation
- **Images:** Fully responsive with `max-width:100%` and `object-fit:cover`

---

## Features
- Smooth **fade‑in animations** using IntersectionObserver
- Modern **hover effects** on buttons, cards, and images
- Accessible navigation with **ARIA labels** and focus outlines
- Consistent design system with **CSS variables**
